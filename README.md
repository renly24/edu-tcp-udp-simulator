# TCP と UDP のちがい（教育用）

トランスポート層の 2 つのプロトコル、**TCP（確実に届ける）** と **UDP（すばやく届ける）** の通信の違いを、時間の流れ図（シーケンス図）とアニメーションで見比べながら学ぶ教育用の Web アプリです。

## 学べること

全5章・20枚のスライドで、問題を解きながら進めます。

1. **TCPとUDP**：トランスポート層の 2 つのプロトコルと、ヘッダの違い（TCP 20 バイト〜／UDP 8 バイト）
2. **つながりを作る**：TCP の 3ウェイハンドシェイク（SYN → SYN＋ACK → ACK）と、いきなり送り始める UDP
3. **確実に届ける（TCP）**：確認応答（ACK）、パケットロスのときの再送、シーケンス番号による並べ替え
4. **すばやく届ける（UDP）**：消えても送り直さない・並べ替えない UDP と、ビデオ通話で「遅れるより欠けるほうがまし」な理由
5. **比べて使い分ける**：TCP と UDP の同時送信シミュレーション、まとめの比較表、仕分け、8問のまとめテスト（採点・見直し付き）

### 見て比べる

- **時間の流れ図**：左右の縦線が機器、上から下へ時間が進み、斜めの矢印がパケットです。矢印が1本ずつかかれていき、「もう一度」で再生し直せます。TCP と UDP の図を横に並べたスライドもあります
- **同時送信シミュレーション**：「ネットワーク」の6文字を 1 文字ずつパケットにして、TCP と UDP で同時に送ります。パケットごとに「届く／消える／遅れる」を選べ、ハンドシェイク・ACK・再送の様子と、受信側のアプリに渡されたデータ・終わるまでの時間を比べられます
- **ビデオ通話の比較**：1コマ消えたとき、TCP は再送を待って映像が止まり、UDP は一瞬乱れるだけで流れ続ける様子

### 問題の種類

- **予想問題**：アニメーションの前に「どうなると思う？」と考える問題。答えるまで次のスライドへ進めません
- **体験問題**：3ウェイハンドシェイクの順番を並べる、同時送信シミュレーションを試す、TCP と UDP を仕分けるなど、自分で操作する問題
- **確認問題**：章の終わりと最後のまとめテスト。まとめテストの結果画面はスクリーンショットで提出する想定です（結果はサーバに保存されません）

パワーポイントのスライドのように、画面下の「前へ」「次へ」ボタンやスライドのクリック・タップで1枚ずつ進めます（← → ・スペースキーでも操作できます。問題のスライドではクリックで進みません）。

## 開発

```bash
npm ci
npm run dev    # http://localhost:3000
npm run build  # out/ に静的ファイルを出力
```

`main` ブランチにプッシュすると、GitHub Actions がビルドして次の2か所に公開します。

- GitHub Pages: https://renly24.github.io/edu-tcp-udp-simulator/ （Settings → Pages で Source を「GitHub Actions」にしておく）
- FTP サーバー: http://e.gmobb.jp/omaesensei/digital/edu-tcp-udp-simulator/ （共通ワークフロー renly24/edu-deploy-workflows を使用）

FTP へのアップロードには、リポジトリの Settings → Secrets and variables → Actions に `FTP_HOST`・`FTP_USER`・`FTP_PASS` の3つを登録しておく必要があります（edu-deploy-workflows の「Sync FTP secrets to repositories」でコピーできます）。
